HW52. Централизованный сбор логов (ELK Stack)

Цель работы:
Развернуть централизованную систему сбора и хранения логов на базе ELK Stack.

Используемые компоненты:
- Elasticsearch
- Logstash
- Filebeat
- Docker Compose
- Nginx (источник логов)

Схема работы:

Nginx
  ↓
Filebeat
  ↓
Logstash
  ↓
Elasticsearch

Ход выполнения:

1. Развернут ELK Stack с помощью Docker Compose.
2. Настроен Filebeat для чтения логов Nginx.
3. Настроен Logstash для приема и обработки логов.
4. Настроен Elasticsearch для хранения событий.
5. Сгенерированы HTTP-запросы к веб-серверу.
6. Проверено создание индексов в Elasticsearch.

Проверка работоспособности:

- Elasticsearch доступен на порту 9200.
- Logstash принимает данные на порту 5044.
- Filebeat успешно отправляет события.
- В Elasticsearch создаются индексы docker-logs-*.
- Логи доступны для поиска и анализа.

Результат:

Реализована централизованная система логирования на базе ELK Stack. Сбор, обработка и хранение логов работают корректно.
